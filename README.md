# 🐞 Milla — Personal Branding Website

Halaman web personal branding milik **Milla**, seorang **QA Engineer** yang juga memiliki ketertarikan pada fotografi, multimedia, dan journaling. Website ini menjadi ruang untuk menampilkan sisi profesional sekaligus kreatif dari dirinya dalam satu tempat.

🔗 **Live site:** https://skyflowersndev.github.io/personal-branding-sederhana/

## ✨ Tentang Halaman Ini

Website ini dibangun sebagai representasi diri Milla — memadukan latar belakang sebagai QA Engineer dengan hobi kreatif seperti fotografi, drawing, multimedia, dan menulis. Temanya sengaja dibuat personal dan hangat, mencerminkan gaya *cute pastel Y2K* yang menjadi ciri khasnya.

## 🧭 Struktur Halaman

| Bagian | Deskripsi |
|---|---|
| **Tentang** | Perkenalan singkat Milla sebagai QA Engineer dan orang di baliknya |
| **Portofolio** | Kumpulan karya kreatif yang terbagi menjadi tiga kategori |
| **Toko** | Ruang untuk produk atau karya yang dijual |
| **Galeri** | Kumpulan visual dari karya-karya Milla |
| **Media** | Tautan ke tulisan/artikel di platform lain |
| **Kontak** | Cara menghubungi Milla |

## 🎨 Kategori Portofolio

- **📷 Photography** — eksplorasi cerita dan komposisi melalui foto
- **🎬 Multimedia** — karya video, audio, dan digital
- **✍️ Artikel** — jurnal dan artikel yang dipublikasikan di platform seperti Medium
